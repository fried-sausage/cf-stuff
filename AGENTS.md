# Guideline

Below are principles for writing utility
scripts for setting up environment & working
with codeforces problems.

You should follow them.

- YAGNI
- KISS
- Don't try to be smart
- Fail Fast
- Simplicity over features
- Correctness over features
- External dependencies are OK, as long
as they simplify the code

# Technical details

We write scripts in python. We use uv to run everyting.
We use pyproject.toml.
